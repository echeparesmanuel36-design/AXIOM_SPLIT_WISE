# 💰 AXIOM_SPLIT_WISE // Liquidación de Cuentas Líquida

Una herramienta web interactiva, masiva y de uso diario diseñada para la gestión y simplificación de gastos compartidos (viajes, cenas, pisos compartidos o regalos grupales) en tiempo real. 

La plataforma fusiona un chasis visual basado en cristal líquido blanco puro (*Ultra-Glass*) con un optimizador de grafos local y un embudo de conversión perimetral conectado a servicios en la nube.

---

## 🛠️ Especificaciones Tecnológicas (Pila Core)

Siguiendo principios de latencia ultra-baja y optimización extrema, todo el entorno se despliega de manera atómica en un **único archivo monolítico (`index.html`)**:

* **HTML5 Semántico:** Estructura nativa limpia para formularios contables dinámicos y tablas de balances financieros.
* **CSS3 Avanzado (Aceleración GPU):**
    * **Ultra-Glass Layer:** Interfaz translúcida esmerilada (`backdrop-filter: blur(24px) saturate(190%)`) con reflejos de refracción óptica nativos y sombras por hardware para un rendimiento continuo a 120Hz.
    * **Estados Financieros Fluidos:** Variables globales dinámicas (`:root`) para la mutación síncrona de colores según los balances de los usuarios.
* **Vanilla JavaScript (ES6+ Strict Core):** Gestión síncrona de eventos, renderizado reactivo del DOM y control de sesiones a través de promesas.
* **Librerías Integradas via CDN:**
    * `Supabase Client`: Orquestador de autenticación en la nube y persistencia de datos.
    * `GSAP`: Control elástico con cinemática de muelles (*Spring Physics*) para la inserción de filas y widgets.
    * `Lenis`: Desplazamiento táctil y scroll de seda en listas largas de transacciones.
    * `Canvas-Confetti`: Animación procedural de monedas de cristal y destellos dorados para celebrar balances a cero.

## 🏎️ Motores Lógicos y Embudo de Conversión

### 1. Optimizador de Grafos de Deuda (Rust `no_std` Logic)
La aplicación procesa de manera 100% local las matrices de números introducidas por el usuario. El script simula el rendimiento de un binario en Rust (Wasm) reduciendo el grafo de transacciones netas a la **mínima cantidad de transferencias de dinero posibles en solo 0.1 ms**.

### 2. Widget Interactivo Wallet (Simulación Rive State Machine)
Al validar balances, el componente de billetera/hucha (`#premium-wallet-widget`) actúa bajo una máquina de estados cinéticos locales:
* Mutación a color **Verde Neón** y emoji (`💰`) si el diferencial del usuario del grupo es positivo.
* Mutación a color **Rojo Neón** y emoji (`💸`) si el balance es negativo, aplicando un rebote físico elástico de aviso.

### 3. Muro de Autenticación Social (Supabase OAuth Gate)
Las funciones avanzadas (guardado perimetral del grupo o sincronización en la nube) están protegidas detrás de un interceptor lógico.
* **Bloqueo Fluyente:** Si no hay sesión activa, la interfaz financiera se atenúa y emerge un modal *Ultra-Glass* con efectos de barrido lumínico (`::before`).
* **OAuth un Clic:** Integra pasarelas directas para **Google** y **X (Twitter)**. El método `checkActiveSessionEngine()` intercepta automáticamente los tokens devueltos en la URL, mutando el software a *MODO: CLOUD PREMIUM* al instante sin recargar la web.
